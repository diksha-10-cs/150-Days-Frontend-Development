# Day 03 – Student Registration Form

**Date:** 21 November 2026

## 1. Learning Objective

Practiced creating a Student Registration Form using HTML and applying basic styling using CSS.

## 2. HTML Tags Learned

| HTML Tag | Purpose |
|---|---|
| `<form>` | Creates a form to collect user information. |
| `<label>` | Provides a label for an input field. |
| `<input>` | Creates input fields. |
| `<textarea>` | Creates a multi-line text area. |
| `<button>` | Creates a clickable button. |
| `<br>` | Adds a line break. |

## 3. HTML Attributes Used

- `type` – Specifies the input type.
- `id` – Gives an element a unique identifier.
- `name` – Defines the name of a form field.
- `for` – Connects a label with an input field.
- `value` – Specifies the value of an input element.

## 4. CSS Properties Learned

| CSS Property | Purpose |
|---|---|
| `background-color` | Sets the background color. |
| `font-family` | Changes the font style. |
| `height` | Sets the height of an element. |
| `margin` | Adds space outside an element. |
| `padding` | Adds space between content and its border. |
| `text-align` | Aligns text. |
| `border` | Adds a border around an element. |
| `color` | Sets the text color. |

## 5. Practical Project

**Project Name:** Student Registration Form

**Description:** Created a basic student registration form with fields for first name, middle name, last name, email, password and a textarea.

### Form Features

- First Name field
- Middle Name field
- Last Name field
- Email field
- Password field
- Textarea field
- Register button

## 6. Project Files

- `index.html` – HTML structure of the registration form.
- `style.css` – CSS styling of the webpage.
- `output.png` – Final webpage screenshot.

## 7. What I Learned

- How to create a form using HTML.
- How to connect labels with input fields.
- How to use different input fields.
- How to create a multi-line textarea.
- How to create a clickable button.
- How to apply a border to the webpage.
- How to use margin and padding.
- How to style a webpage using CSS.

## 8. Challenges and Improvements

- Initially used an input field instead of the `<textarea>` tag.
- Learned how to create a proper textarea.
- Faced difficulty applying a border correctly.
- Learned to apply the `border` property to the body.
- Used `padding: 20px` to create space between the content and border.
