## 2. HTML Tags and Concepts Learned

| HTML Tag / Attribute | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares the HTML5 document type. |
| `<html>` | Defines the HTML document. |
| `lang="en"` | Specifies the document language as English. |
| `<head>` | Contains webpage information and linked resources. |
| `<meta charset="UTF-8">` | Defines character encoding. |
| `<meta name="viewport">` | Helps the webpage display on different screen sizes. |
| `<title>` | Sets the webpage title. |
| `<link>` | Connects an external CSS file. |
| `<body>` | Contains the visible webpage content. |
| `<h1>` | Defines the main heading. |
| `<p>` | Defines a paragraph. |
| `<b>` | Makes text bold. |
| `<hr>` | Adds a horizontal line. |
| `<a>` | Creates a hyperlink. |

### HTML Attributes Used

- `href` – Specifies the link destination.
- `target="_blank"` – Opens the link in a new tab.
- `rel="noopener"` – Adds a security-related attribute when opening a new tab.

3. CSS Properties Learned

| CSS Property | Purpose |
|---|---|
| `background-color` | Sets the background color. |
| `color` | Sets the text color. |
| `font-family` | Changes the font style. |
| `font-size` | Controls the text size. |
| `text-align` | Aligns the text. |

 4. CSS Selectors Used

- `body` – Selects the webpage body.
- `h1` – Selects the main heading.
- `.p` – Selects an element using its class.
- `p` – Selects paragraph elements.
- `a` – Selects hyperlink elements.
