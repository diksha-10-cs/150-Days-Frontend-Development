## 2. HTML Tags Learned

| HTML Tag | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares the HTML5 document type. |
| `<html>` | Defines the HTML document. |
| `<head>` | Contains webpage information and linked resources. |
| `<meta>` | Provides metadata about the webpage. |
| `<title>` | Sets the webpage title. |
| `<link>` | Connects an external CSS file. |
| `<body>` | Contains visible webpage content. |
| `<h1>` | Defines the main heading. |
| `<p>` | Defines a paragraph. |
| `<b>` | Makes text bold. |
| `<hr>` | Adds a horizontal line. |
| `<a>` | Creates a hyperlink. |

## 3. HTML Attributes Used

- `lang` – Specifies the document language.
- `charset` – Defines character encoding.
- `name` – Specifies metadata information.
- `content` – Provides metadata values.
- `href` – Specifies the link destination.
- `rel` – Defines the relationship with a linked resource.
- `target="_blank"` – Opens a link in a new tab.
- `class` – Assigns a class name to an element.

## 4. CSS Properties Learned

| CSS Property | Purpose |
|---|---|
| `background-color` | Sets the background color. |
| `color` | Sets the text color. |
| `font-family` | Changes the font style. |
| `font-size` | Controls text size. |
| `text-align` | Aligns text. |
